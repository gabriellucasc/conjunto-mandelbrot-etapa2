# Imagens para inspeção visual

Os dois PGM (P5, 16 bits, big-endian) foram derivados das matrizes binárias de referência de 4096 × 4096 preservadas na bateria oficial. O nível de cinza é a própria contagem de iterações, sem perda; o máximo declarado é 1000 no padrão e 5000 no zoom. Não representam nova execução nem novos tempos de benchmark.

Atendem à saída auxiliar PGM/PPM para inspeção visual da Seção 5.4 do enunciado. A validação numérica continua sendo feita sobre os arquivos `.bin` originais. O teste de leitura confirmou igualdade de todas as contagens entre cada PGM e o binário correspondente.
